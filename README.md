# 🚀 Modern Full-Stack Developer Portfolio

A sleek, responsive, and interactive personal portfolio website designed to showcase web development skills and professional projects. It features fully functional **Light Mode** and **Dark Mode** themes with smooth transitions, modern gradients, and dynamic layout rendering.

---

## ✨ Features

- **🌓 Dynamic Theme Toggling**: Easily switch between high-contrast dark mode and clean light mode via a dedicated interactive theme toggle button.
Light Mode:
- **📱 Fully Responsive Design**: Seamlessly adapts to all screen sizes from mobile devices and tablets up to wide desktop monitors.
- **🛠️ Structured Sections**:
  - **Hero Landing Page**: Catchy title, subtitle, and an actionable "View Work" call-to-action button.
  - **Skills Showcase**: Visual breakdown of core technical proficiencies featuring clean badges (HTML5, CSS3, JavaScript).
  - **Interactive Project Filter**: Categorized view of projects allowing visitors to filter by types like "All", "Web", and "Apps".
- **🎨 Modern Visuals**: Equipped with vibrant blue gradients, custom logos, elegant card container selections, and clean typography.

- **HTML5**: semantic document structure.
